# MyTodo

카테고리·검색·드래그앤드롭을 지원하는 심플한 할 일 관리 앱입니다.
빌드 도구 없이 HTML/CSS/JS 세 파일로 동작합니다.

## 실행 방법

`index.html`을 브라우저에서 바로 열면 됩니다.

```bash
# Windows
start index.html

# macOS
open index.html
```

## 주요 기능

### 할 일 관리
- 추가 / 수정 / 삭제 (삭제 시 확인 다이얼로그)
- 더블클릭 또는 ✎ 버튼으로 인라인 편집
- 완료 체크 — 모두 완료 시 축하 토스트 표시

### 카테고리
| 키 | 라벨 | 색상 |
|----|------|------|
| `work` | 업무 | 파랑 |
| `personal` | 개인 | 초록 |
| `study` | 공부 | 보라 |

### 검색 & 필터
- 실시간 텍스트 검색 (150ms 디바운스)
- 카테고리별 필터

### 정렬
- 최신순 / 오래된순 / 카테고리순 / 미완료 우선
- 드래그앤드롭 수동 정렬 — 정렬 상태 저장

### 데이터 내보내기 / 가져오기
- JSON 파일로 내보내기
- JSON 파일 가져오기 (기존 데이터 자동 백업 후 교체)

### 기타
- 다크 모드 토글
- 전체 및 카테고리별 진행률 대시보드
- 오늘 추가한 항목 수 표시
- `localStorage` 자동 저장

## 키보드 단축키

| 단축키 | 동작 |
|--------|------|
| `Enter` | 할 일 추가 |
| `Alt + N` | 입력창으로 포커스 이동 |
| `Alt + 1` | 전체 필터 |
| `Alt + 2` | 업무 필터 |
| `Alt + 3` | 개인 필터 |
| `Alt + 4` | 공부 필터 |
| `Esc` | 다이얼로그 닫기 |

## 구조

```
index.html   — DOM 구조
style.css    — CSS 커스텀 프로퍼티 기반 스타일
app.js       — 상태·로직·렌더링
```

### 성능
- **Keyed Reconciliation** — 변경된 항목만 DOM 업데이트
- **이벤트 위임** — 리스트 전체에 리스너 1개
- **`content-visibility: auto`** — 화면 밖 항목 렌더링 스킵 (100+ 항목에서도 부드러운 스크롤)
